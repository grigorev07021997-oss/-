# Контур — демо аналитики VK

Статический адаптивный прототип на HTML, CSS и JavaScript. Все показатели — демонстрационные. Реальные VK Реклама и Senler не подключены, авторизации и отправки сообщений нет.

Откройте index.html или включите GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).

Проекты и отчёты сохраняются только в браузере пользователя. На сервер и в этот репозиторий введённые в интерфейсе данные не отправляются. Не вводите секреты и настоящие ключи доступа.
